# Panda AI Desktop Agent 产品需求文档 (PRD V1.7)

## 一、 产品概述

Panda AI 是一款常驻桌面的 **Personal AI Agent**。产品采用 `Tauri 2 (Rust) + React` 架构。所有重型推理能力完全托管于用户自定义配置的云端 API（Bring Your Own Key）。产品通过分阶段、精细化的依赖控制，在第一阶段（Phase 1）实现 **30MB 级别**的极轻量常驻，后续逐步平滑演进为用户的**第二大脑与个人工作流引擎**。

---

## 二、 演进式系统架构与依赖控制

随着版本的迭代，底层依赖和包体积采用**渐进式膨胀**策略，保障前期开发的敏捷性：

```
[Phase 1: 极简壳]  Tauri 2 + SQLite(sqlx) + reqwest                  -> 约 30MB
[Phase 2: 知识库]  + LanceDB (Rust SDK)                               -> 约 55MB
[Phase 3: 行动派]  + Rust State Machine + EdgeTTS(tokio)              -> 约 60MB

```

---

## 三、 重新精剪后的四阶段路线图

### 🚀 Phase 1：V1.0 极致 MVP —— “30MB 的全能对话桌宠”

* **核心目标**：跑通 Tauri 2 置顶透明特性，上线 API 配置，实现极低内存常驻的完整文本聊天闭环。
* **核心功能**：
1. **桌面特性**：无边框透明窗口、边缘自动隐藏（吸附）、置顶/取消置顶切换、鼠标穿透。
2. **动画落地**：通过 APNG / 序列帧精灵图实现 Idle（常态）、Thinking（思考）、Error（异常）三种基础情感动画。
3. **API 配置中心**：支持用户输入标准 OpenAPI 规范的 Key 与自定义 Base URL（完美兼容 DeepSeek、OpenAI、硅基流动等）。
4. **长上下文文件直传**：支持拖拽单个 Markdown/TXT/PDF 文件到桌宠上，Rust 端纯文本提取，直接作为 Context 送入云端长文本模型。
5. **最小化对话管理**：本地 SQLite 记录聊天历史，前端支持“新建对话”与“历史列表查看”，防止上下文无限拉长。
6. **UX 错误联动**：当 API 超时或 Key 失效时，桌宠切换为“抓头/无精打采”动画，并引导用户检查配置。



### 🛠️ Phase 2：V2.0 空间进化 —— “标准本地第二大脑（LanceDB）与视觉”

* **核心目标**：引入 LanceDB，在不消耗本地算力的前提下，搞定个人多文件知识管理与多模态感知。
* **核心功能**：
1. **激活 LanceDB RAG**：正式引入 `lancedb` 纯 Rust 依赖。支持多文件、整个资料文件夹的批量导入。本地切片后，调用云端 Embedding API 转换，在本地 LanceDB 实现海量小说大纲、工作资料的混合检索。
2. **云端视觉（Vision）**：支持屏幕截图快捷键、或拖拽图片给桌宠。利用云端多模态 API（如 GPT-4o、Claude 3.5）进行图文问答、表格摘录和 OCR 识别。
3. **交互动画扩展**：增加 Executing（翻书检索中）动画。



### 🧠 Phase 3：V3.0 Agent 跃迁 —— “多手多脚的桌面秘书（MCP + 记忆）”

* **核心目标**：在 Rust 侧跑通轻量 Agent 状态机，正式接入长期记忆与办公生态。
* **核心功能**：
1. **纯 Rust Agent 状态机**：由 Rust 侧的状态机接管任务编排，通过大模型 Function Calling 返回的 JSON 指令，循环调度工具。前端上线可视化的 Trace 步骤条。
2. **MCP 生态集成**：作为 MCP 客户端，支持调用标准的 MCP 服务端工具（本地文件系统读写、浏览器搜索、Google日历、Notion等）。
3. **触发式长期记忆**：上线“会话完结/闲时批处理”内省机制。后台自动提炼本轮对话中的用户画像（如职业、兴趣、下周日程），单次调用云端大模型提炼并更新至 SQLite 记忆表。
4. **低消耗语音交互**：引入浏览器内置的 Web Speech API（前端 ASR 零体积）+ 纯 Rust 异步调用的 EdgeTTS（云端免 Key TTS），实现高音质、零显存消耗的双向语音对话。



### 🌐 Phase 4：V4.0 终极形态 —— “主动感知与个人 AI OS”

* **核心目标**：具备主动提醒和受控的跨软件自动化调度能力。
* **核心功能**：
1. **本地轻量图谱可视化**：利用 SQLite 关系表维护节点和边，前端 React 渲染星系状的知识/人物关系网络拓扑图（满足创作者构建小说设定、人物关系网的需求）。
2. **系统级主动助手**：根据工作时间、系统部分日程，结合工作记忆进行主动关怀和重要弹窗提醒。
3. **计算机控制（Computer Use）**：在用户完全授权的受控环境下，利用具有视觉能力的云端 Agent，通过模拟鼠标键盘执行跨软件的复杂宏任务。
